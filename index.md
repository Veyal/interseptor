<section class="hero"><p class="eyebrow">HUMAN-LED · AGENT-ASSISTED</p><h1>See traffic.<br><em>Test with intent.</em></h1><p class="lede">Interseptor is a native HTTP/HTTPS intercepting proxy and security-testing toolkit. One static Go binary. Deterministic capture, replay, mutation, scanning, scope, evidence, and findings.</p><div class="actions"><a class="button primary" href="{{ '/getting-started/' | relative_url }}">Start here</a><a class="button" href="{{ '/features/' | relative_url }}">Explore features</a></div></section>
<section class="grid cards"><article><span class="card-number">01</span><h2>Proxy first</h2><p>Capture HTTP and HTTPS through a local CA. Hold, edit, forward, or drop requests and responses while keeping history searchable.</p><a href="{{ '/features/#intercepting-proxy' | relative_url }}">Proxy workflow →</a></article><article><span class="card-number">02</span><h2>Evidence built in</h2><p>Replay and mutate requests, run passive checks, and preserve flows, activity, and report-ready findings.</p><a href="{{ '/features/#scanner' | relative_url }}">Testing workflow →</a></article><article><span class="card-number">03</span><h2>Agents stay external</h2><p>Use MCP or REST/SSE to drive the same engine. Interseptor records actions; your model owns reasoning and sequencing.</p><a href="{{ '/api-and-mcp/' | relative_url }}">API reference →</a></article></section>
<section class="notice"><strong>Responsible use.</strong> Test systems you own or are explicitly authorized to test. Interseptor has no built-in model provider or autonomous decision loop.</section>
<section class="split"><div><p class="eyebrow">QUICK PATH</p><h2>From install to first flow</h2><ol class="steps"><li><a href="{{ '/getting-started/#install' | relative_url }}">Install</a> a release or use <code>go install</code>.</li><li>Point traffic at <code>127.0.0.1:8080</code>.</li><li>Open the control UI at <code>127.0.0.1:9966</code>.</li><li>Trust local CA, set scope, inspect History.</li></ol></div><div class="terminal"><span>$</span> interseptor<br><span class="muted">proxy  127.0.0.1:8080</span><br><span class="muted">control 127.0.0.1:9966</span></div></section>
